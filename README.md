# 🎮 Projeto: GTA IA

O **GTA IA** é uma aplicação web inspirada no universo de Grand Theft Auto, desenvolvida para oferecer uma experiência interativa de escolha de personagens e personalização através de imagens.

A aplicação apresenta personagens do universo GTA, permitindo que o usuário selecione seu personagem favorito ou escolha uma fotografia própria através do upload de uma imagem.

A interface foi desenvolvida com foco na identidade visual do jogo, utilizando imagens personalizadas, efeitos de interação (hover), animações suaves e elementos visuais inspirados no universo de GTA.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com integração da biblioteca **Puter.js** para recursos relacionados à inteligência artificial.

## 🔍 Como funciona?

Ao acessar a aplicação, o usuário encontra uma interface inspirada no universo de GTA, com personagens disponíveis para seleção.

É possível escolher entre os personagens apresentados, como Lucia, Jason e CJ. Ao selecionar um deles, a aplicação utiliza JavaScript para atualizar as informações e a imagem do personagem escolhido.

Além disso, o usuário pode clicar na opção de fotografia para selecionar uma imagem diretamente do seu dispositivo.

A aplicação utiliza **HTML** para estruturar os elementos, **CSS** para desenvolver a identidade visual e **JavaScript** para implementar as interações e funcionalidades.

Também conta com a integração da biblioteca **Puter.js**, utilizada como recurso para funcionalidades relacionadas à inteligência artificial.
